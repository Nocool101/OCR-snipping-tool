# 01: 设置与配置持久化

**What to build:** 一个能启动并常驻托盘的 Windows 程序，托盘菜单里能打开**设置**窗口，填写**模型**的接口地址、API Key、模型名，以及**热键**和「开机自启」开关。保存后配置落到磁盘，重启程序仍然在。

**Blocked by:** 无（可立即开始）

**Status:** ready-for-agent

- [x] 程序启动后托盘出现图标，不占任务栏窗口
- [x] 托盘菜单能打开**设置**窗口
- [x] 设置里能填模型接口地址、API Key、模型名、热键、开机自启开关
- [x] 保存后退出程序再启动，设置仍在
- [x] 首次启动（无配置文件）时各项有可用默认值，热键默认为 `Ctrl+Alt+O`
- [x] 配置文件损坏时程序不崩溃，回落到默认值
- [x] `SettingsStore` 有自动化测试：默认值、写入后读回、字段缺失、文件损坏
- [x] 托盘菜单有「退出」，能真正结束程序

**Comments**

代码审查（Standards / Spec 两轴）结论：八条验收全部满足，无硬违规。遗留轻微问题，留到后续票处理：

- 应用名 `"screenshot-ocr"` 在 `paths.APP_DIR_NAME`、`autostart.VALUE_NAME`、`main.py` 三处重复。
- 配置字段类型错误（如 `autostart: "false"` 字符串）未校验，会被当成真值。
- 配置损坏时静默回落默认值，用户无从知晓 API Key 被丢弃。
- `autostart.apply` 失败时界面仍显示已开启。自启仅在保存时应用，启动时不核对注册表。
