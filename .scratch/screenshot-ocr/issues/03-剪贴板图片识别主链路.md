# 03: 剪贴板图片识别主链路

**What to build:** 第一条真正跑通的**识别**竖切。托盘菜单点「识别剪贴板图片」，程序读剪贴板里的图片，交给**模型**识别，**结果窗口**弹出，**文本**流式逐字出现，可以一键复制。这条链路先绕开截图与热键，把「图片 → 文字 → 窗口」验通。

**Blocked by:** 01、02

**Status:** ready-for-agent

- [ ] 托盘菜单有「识别剪贴板图片」项
- [ ] 剪贴板有图片时：结果窗口弹出并显示「识别中…」，随后文本流式出现
- [ ] 剪贴板无图片时：给出明确提示，不弹空窗口
- [ ] 识别指令要求逐字提取图中全部文字、保留换行、除文字外不加解释
- [ ] 结果窗口上半区是可编辑的纯文本，底部有「复制」按钮
- [ ] 复制按钮把当前（可能已编辑的）文本放进剪贴板
- [ ] `AppController` 有自动化测试（模型客户端用假实现）：流式片段正确拼接、文本可被替换为编辑后的值
- [ ] `PromptBuilder` 有自动化测试：识别指令包含「逐字提取/保留换行/不加解释」的约束
