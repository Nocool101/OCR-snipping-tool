# 04: 全局热键 + 全屏框选截图

**What to build:** 按下**热键**（默认 `Ctrl+Alt+O`）进入截图模式：整个虚拟桌面（含多显示器）覆盖半透明遮罩，拖框选中区域的画面是亮的，松开鼠标即把该**截图**送入第 03 条已有的识别链路。按 `Esc` 取消。进入截屏前先隐藏本工具的窗口。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 按 `Ctrl+Alt+O` 进入截图模式，覆盖全部显示器
- [ ] 遮罩半透明，拖出的选区是亮的，能看清框了哪块
- [ ] 松开鼠标立即开始识别，无需二次确认
- [ ] 按 `Esc` 退出截图模式，不产生任何识别
- [ ] 截图模式期间本工具自身窗口不可见，不会截到自己
- [ ] 在缩放不为 100% 的显示器与多显示器布局下，框选区域与实际截取内容一致
- [ ] 热键注册失败（被别的软件占用）时给出提示并引导去**设置**改键
- [ ] 截出的图片可直接交给 `AppController` 识别（与剪贴板路径共用同一入口）
