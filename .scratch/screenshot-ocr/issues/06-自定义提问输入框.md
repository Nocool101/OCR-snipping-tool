# 06: 自定义提问输入框

**What to build:** **结果窗口**底部内置一个输入框，自己写一句指令（如「这段代码有什么问题」），回车后连同当前**文本**一起交给**模型**，答案流式显示在下半区。

**Blocked by:** 03、05

**Status:** ready-for-agent

- [ ] 结果窗口底部有输入框，可输入任意指令
- [ ] 回车即发送，指令与当前文本一并交给模型
- [ ] 答案在下半区流式显示，与动作答案共用同一块渲染区
- [ ] 输入框在请求进行中禁用或忽略重复回车，避免并发请求
- [ ] `PromptBuilder` 有自动化测试：自定义提问把用户指令并入，且文本作为被处理内容
