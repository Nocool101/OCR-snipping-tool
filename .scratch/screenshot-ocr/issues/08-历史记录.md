# 08: 历史记录

**What to build:** 托盘菜单里能回看本次运行识别过的记录（最近若干条，如 20 条），点一条能重新看到那次的**文本**。记录只在内存里，关掉程序即清空。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 每次识别都把文本追加进内存历史
- [ ] 托盘菜单有「历史」入口，列出最近若干条（带时间与文本开头）
- [ ] 点历史某一条能打开**结果窗口**显示那条文本
- [ ] 历史超过上限时淘汰最旧的
- [ ] 程序退出后历史不落盘，重启为空
- [ ] `AppController` 有自动化测试：历史按上限淘汰、顺序正确
