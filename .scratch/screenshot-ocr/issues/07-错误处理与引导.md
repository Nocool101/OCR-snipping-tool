# 07: 错误处理与引导

**What to build:** 把失败变成看得懂的话。没配 API Key 就用**热键**截图时，直接引导打开**设置**窗口；网络失败或**模型**返回错误时，在**结果窗口**里给出说清原因的提示，而不是永远转圈。

**Blocked by:** 03

**Status:** ready-for-agent

- [x] 未配置 API Key 时触发识别，直接打开设置窗口并提示需要先配置
- [x] 网络不通时，结果窗口显示「网络错误」类提示，可重试
- [x] 模型返回错误（鉴权失败、模型名不存在、限流等）时，提示里体现原因
- [x] 任一失败都不会让程序卡住或崩溃，窗口仍可关闭
- [x] `AppController` 有自动化测试（模型客户端用假实现抛各类失败）：缺 Key、网络错误、模型错误被正确分类

**Comments**

**新增「重试」按钮**：失败后结果窗口出现「重试」，重跑上一次失败的操作（同一张截图，或同一段文本与问题），成功后按钮隐藏。`AppController` 本身不需要改动——异常本就是原样向上传递的。

**缺 Key 引导**：`_start_recognition` 在发起前检查，没有 API Key 就提示并打开**设置**窗口，不弹结果窗口。

**截断检测（本票消化 02 留下的缺口）**：先实测确认目标端点确实以 `data: [DONE]` 收尾（响应头 `Transfer-Encoding: chunked`、`Connection: close`，末行 `data: [DONE]`），因此「读到 EOF 却没见到 `[DONE]`」可作为截断判定。新增 `ModelTruncated`，与网络错误一同纳入「未产出前可重试」的策略——截断发生在已产出之后时无法重试，只能报错（重试会重复输出）。

**真机验证**（结果窗口用假模型客户端，其余为真实控件）：

- 缺 Key：引导打开设置，不弹结果窗口。
- 网络失败：状态显示「识别失败：网络错误：连接被重置」，出现可点的重试按钮；点击后重跑成功、按钮隐藏。
- 鉴权失败：状态显示「识别失败：鉴权失败（HTTP 401）：Invalid API key」——原因来自供应商返回体。
- 截断：状态显示对应提示；失败后编辑器可编辑、提问框可用。

**代码审查（Standards / Spec 两轴）后修复**

- **验收项原本没真正满足**：票面要求 `AppController` 层有失败分类的自动化测试，而当时只有 `ModelClient` 层的测试（另一个接缝）。补上控制器层测试：三类失败原样向上传递、失败时控制器文本不被写坏。
- `ModelTruncated` 原继承 `ModelNetworkError`——语义不诚实（截断不是"网络不通"），且会被任何 `except ModelNetworkError` 顺带吞掉。改为继承 `ModelError`，重试策略里显式写成 `except (ModelNetworkError, ModelTruncated)`。
- 截断提示原为「模型响应被截断（没收到结束标记）」，会把「接口地址填错、服务返回了非 SSE 内容」这种配置问题也报成截断——改为「模型响应不完整（没收到结束标记），请检查接口地址与模型名是否正确」，把引导补回来。
- `open_settings` 无重入保护：设置窗口是模态的，若在遮罩的截图回调里弹出，期间再按热键可能叠出多个设置窗口——加 `_settings_open` 守卫。

**刻意保留（记录备查）**

- 重试用的是**首次失败时那一刻**的文本与问题。用户在失败后编辑了文字再点重试，重试的仍是旧内容——「重试上次请求」的字面语义如此。若要「用当前内容重试」，应改为重新读取编辑器。
- `_last_attempt` 闭包会持有截图字节直到窗口销毁；闭包是自引用环，可被 GC 回收，不是硬泄漏。


**Comments**

**从 02 带过来的已知缺口（本票处理）**

SSE 响应体被**干净地**截断时（服务端正常 FIN 而非 RST），`urllib` 的逐行迭代会静默结束——客户端无法区分「正常结束」与「只收到半截」。表现为用户看到一个**不完整却没有报错**的答案。云端偶发断连时这是真实存在的（02 里观测到约 10% 的连接失败率，重试已覆盖大部分，但断在流中途时重试也无能为力）。

可能的解法：OpenAI 兼容协议以 `data: [DONE]` 标记结束，因此「读到 EOF 却没见到 `[DONE]`」即为截断，可据此报错。但某些兼容服务可能不发 `[DONE]`，贸然强制会让本来能用的供应商报错——需要先确认目标端点（本项目的 opencode-go 端点是发的）。是否采用、以及是否在提示里加「可重试」，留到本票决定。
