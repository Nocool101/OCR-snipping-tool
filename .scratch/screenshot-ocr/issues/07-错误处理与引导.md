# 07: 错误处理与引导

**What to build:** 把失败变成看得懂的话。没配 API Key 就用**热键**截图时，直接引导打开**设置**窗口；网络失败或**模型**返回错误时，在**结果窗口**里给出说清原因的提示，而不是永远转圈。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 未配置 API Key 时触发识别，直接打开设置窗口并提示需要先配置
- [ ] 网络不通时，结果窗口显示「网络错误」类提示，可重试
- [ ] 模型返回错误（鉴权失败、模型名不存在、限流等）时，提示里体现原因
- [ ] 任一失败都不会让程序卡住或崩溃，窗口仍可关闭
- [ ] `AppController` 有自动化测试（模型客户端用假实现抛各类失败）：缺 Key、网络错误、模型错误被正确分类
