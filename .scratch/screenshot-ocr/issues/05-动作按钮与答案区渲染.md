# 05: 动作按钮 + 答案区 Markdown 渲染

**What to build:** **结果窗口**分成上下两区：上半区是识别出的可编辑**文本**，下半区显示**动作**的答案并渲染 Markdown。三个动作按钮：翻译成中文、总结、表格转换。点一下，答案在下半区流式逐字出现。动作以「当前编辑后的文本」为输入。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 结果窗口下半区为渲染 Markdown 的答案区（粗体、列表、代码块、表格）
- [ ] 「翻译成中文」按钮：把当前文本翻成中文，答案流式显示在下半区
- [ ] 「总结」按钮：给出当前文本的几句话概括
- [ ] 「表格转换」按钮：把文本中的表格转成 Markdown 表格
- [ ] 上半区始终是纯文本编辑框，不被 Markdown 渲染影响
- [ ] 每次动作都取「当前编辑后的文本」，而非最初的识别结果
- [ ] 同一次识别可连续做多个动作，答案随之更新
- [ ] `PromptBuilder` 有自动化测试：三个动作各自产出预期指令
