# 02: 模型客户端 + 设置里的「测试连接」

**What to build:** 与**模型**通信的那一层打通，并在**设置**窗口里给一个「测试连接」按钮——用当前填的配置真发一次请求，成功或失败当场看得见。这样「与模型对话」这条链路可以脱离截图单独验证。

**Blocked by:** 01（设置与配置持久化）

**Status:** ready-for-agent

- [ ] 设置窗口有「测试连接」按钮，点了用当前配置发一次纯文字请求
- [ ] 成功时显示模型的简短回答，失败时显示失败原因
- [ ] 客户端以流式方式接收文字（`stream: true`），能逐块取出增量文本
- [ ] 请求使用配置里的接口地址、API Key、模型名
- [ ] 缺 Key、网络错误、HTTP 错误码、超时被区分为可分类的失败
- [ ] 客户端有自动化测试：起本地假 HTTP 服务，断言请求形状（基址、鉴权头、模型名）与 SSE 增量的解析
